# LinguaApp

Учебный сайт на React, Tailwind CSS и Node.js. Страницы сайта открываются отдельно: главная `/`, каталог `/learn`, урок `/learn/0-0`, словарь `/dictionary`, переводчик `/translator`, профиль `/profile`.

## Запуск

Нужен Node.js 22.13 или новее.

1. Распакуйте проект в отдельную папку.
2. В этой папке выполните:

```bash
npm install
npm run dev
```

Откройте адрес Vite, показанный в терминале (обычно `http://localhost:5173`). Для production-сборки используйте `npm run build`, затем `npm start`.

При первом запуске сервер автоматически создаёт SQLite-базу `server/data/lingua.sqlite` и секрет подписи сессий в `.env`. Не удаляйте эти файлы, если хотите сохранить аккаунты и прогресс.

## Что работает

- Регистрация и вход; пароли хранятся как криптографические scrypt-хеши.
- Прогресс, личный словарь, серия занятий и друзья хранятся в SQLite на сервере. Вход сохраняется защищённой HttpOnly-cookie на 30 дней.
- 172 урока на уровнях A1, A2, B1, B2, C1 и C2; уроки включают цели, объяснения, лексику и упражнения.
- Отдельные страницы, словарь из пройденных уроков, серии занятий, личные рекорды, друзья и XP-дуэли на 24 часа. Светлая и тёмная темы, адаптация под узкие экраны.
- Перевод между английским, русским и узбекским через публичный endpoint Google Translate, с MyMemory в качестве резервного сервиса.
- Иконки подключены из `react-icons`.

Переводчик обращается к внешним бесплатным сервисам. Если основной сервис недоступен, используется MyMemory; у его анонимного режима лимит 5 000 символов в сутки. Endpoint Google публичный и может измениться без предупреждения. Не отправляйте конфиденциальный текст.

На главном экране и пользовательских страницах нет инструментов разработчика; отдельную административную панель можно добавить позднее.


## Оценка уровня и учебный план

После регистрации пользователь отвечает на короткую анкету о цели и времени занятий, затем проходит диагностику из 18 вопросов (по три на уровень A1–C2). Результаты и самый высокий уровень с результатом не ниже 80% становится стартовым; анкета показывается один раз, данные сохраняются в серверном аккаунте. Проценты показывают долю ответов в короткой диагностике, а не вероятность сдать полноценный экзамен. Для перехода на следующий уровень нужно завершить 80% уроков текущего уровня и набрать минимум 75% в итоговой проверке.
